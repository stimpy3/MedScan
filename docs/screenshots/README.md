# Screenshot capture list

The main README's demo table expects these 9 files, **with these exact names**, in this folder. Capture in phone portrait (any modern device size; consistent device across all shots looks best).

| File | What to capture |
|---|---|
| `home.png` | Home screen — the 4 feature cards + chat input bar visible |
| `scan.png` | Mid-scan moment: camera view on a medicine strip, or the chat right after a scan showing the 4-intent chooser |
| `explain.png` | A full MedicineCard in chat (pick a well-known medicine like Dolo 650 so composition/side-effects are populated) |
| `alternatives.png` | The alternatives carousel with 2–3 cards and price-savings visible |
| `compare.png` | A side-by-side ComparisonCard for two medicines |
| `safety.png` | An explain card **with warning rows showing** — use a profile that conflicts with the medicine (e.g. kidney condition + an NSAID like ibuprofen) so high/medium severity rows render |
| `schedule.png` | The in-chat schedule form (ScheduleFormCard) filled in |
| `reminders.png` | The reminders page — ideally with the duplicate-therapy banner visible (schedule two same-salt medicines to trigger it) |
| `profile.png` | The profiles page — member switcher + the health form (allergies/conditions chips populated) |

Drop the PNGs here and the README demo table lights up — no other changes needed.
