# Chat Flow

Draft flow for the current chat experience.

```text
User types freely
       ↓
Claude classifies intent confidence
       ↓
High confidence → ask 1 guided follow-up to confirm + get missing info
Low confidence  → disambiguation dropdown (your 4 options)
       ↓
User confirms / selects
       ↓
If prescription needed → show upload UI inline in chat
       ↓
Structured result card renders in chat
```

Use this as the working reference for the chat interaction flow for now.
